# Contributing

Additions and corrections are welcome. These are the same rules the front page states, in one place.

## What gets listed

- Skills, tools, guides and other resources that work with Google Antigravity: Antigravity 2.0, the Antigravity CLI or the Antigravity IDE.
- The link opens and the project is reachable by anyone. Closed-source tools are fine if the line says so.
- One entry per project.

## What is left out

Projects that only exist to share or swap accounts, dodge quotas or get around regional limits are left out on purpose. Please do not submit them.

## How to add an entry

1. Fork this repository.
2. Add your link to the section where it fits, one line, saying what it does and not how great it is. The format is `- [Name](https://link) - What it does.`
3. If the project's own readme says in plain words which Antigravity program it works in, you can add the tag `CLI` or `IDE` at the end of the line.
4. Open a pull request. The form shows a short checklist.

Dead link or wrong description? A pull request that fixes or removes the line is just as welcome.

## Conduct

Please follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/0/code_of_conduct/).
